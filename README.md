# Loan Portfolio Risk & Default Analysis📉

## 🔷 Key Finding

Default risk is heavily concentrated in **low-income and low-credit borrowers**, especially when combined with **high loan amounts**, driving disproportionate portfolio risk.

---

## 🔷 Overview

End-to-end analysis using SQL and Power BI to identify key drivers of loan default and exposure across borrower segments.

---

## 🔷 Dashboard Preview

![Dashboard](Power%20BI/Dashboard%20preview.png)

---

## 🔷 Key Insights

* Low-credit borrowers default significantly more (**12.8%**)
* High-income group holds majority exposure (**~55%**)
* Highest risk segment: **low-income + high loan (~24%)**
* Larger loans increase both **risk (14.5%)** and **exposure (~20.9bn)**
* Combined low income + low credit drives peak default probability (**18–24%**)

---

## 🔷 Business Impact

* High-risk segments contribute disproportionately to losses.
* Loan size amplifies financial exposure.
* Portfolio risk is concentrated, not evenly distributed.

---

## 🔷 Tools Used

* SQL
* Power BI

---
## 🔷 Conclusion

The analysis highlights that default risk is concentrated in specific borrower segments, particularly where low income, low credit score, and high loan amounts intersect.

These insights enable better risk control, improved lending strategies, and more balanced portfolio management.
